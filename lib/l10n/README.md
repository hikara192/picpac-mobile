# Локализация PicPac Mobile

Два языка: русский (`app_ru.arb`, шаблон) и белорусский (`app_be.arb`). Файлы
генерируются в `app_localizations*.dart` командой `flutter gen-l10n` (настройки в
`l10n.yaml`, вывод — в этот же каталог).

## Как добавить строку

1. Добавить ключ в `app_ru.arb` **вместе с `@ключ`**: `required-resource-attributes: true`
   не даст собрать проект без атрибута.
2. Добавить тот же ключ с теми же плейсхолдерами в `app_be.arb`.
3. `flutter gen-l10n` — падает, если в переводе лишний/неизвестный плейсхолдер.
4. `flutter test test/l10n` — падает, если наборы ключей или плейсхолдеры расходятся.

Счётные строки — только ICU-плюралы (`{count, plural, …}`), без склейки числа и слова.
`ru` и `be` используют одни категории: `one` (1, 21), `few` (2–4, 22–24),
`many` (0, 5–20, 11–14), `other` (дробные).

## Решения перевода

- `assumption:` **заказ → «замова»**. Литературная норма белорусского; разговорное
  «заказ» не используется, чтобы не смешивать два словаря в одном экране.
- `assumption:` **срок → «сут.»** в `productEta`, `cartEta`, `deliveryDays`. Шаблон
  не плюральный (в русском стоит сокращение «дн.»), а «1 дзён» неверно; «сут.»
  читается при любом числе. При переводе этих ключей в плюралы — вернуть «дзень/дні/дзён».
- `assumption:` **ЕРИП → «АРІП»** (Адзіная разлікова-інфармацыйная прастора) — официальное
  белорусское название системы; «ЕРИП» в белорусском тексте было бы русизмом.
- **Эндонимы не переводятся**: «Беларуская» и «Русский» названы на своих языках
  (`profileLanguageRu` / `profileLanguageBe`).
- `юридические термины` (удаление аккаунта, возврат средств) переведены дословно и
  нейтрально; при появлении юридически значимого текста он должен прийти с сервера,
  а не из ARB.

## Форматирование

Числа, деньги и даты — через `intl` по локали (`Fmt`/`MoneyFormatter`): `1 234,50 BYN`
с неразрывным пробелом, `12 лістапада 2026`, `12 ліс, 14:30`. Даты всегда `toLocal()`:
часовой пояс — пользовательский. Миллиметры — один десятичный знак, запятая в обеих
локалях.
