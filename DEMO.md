# Демо PicPac Mobile — 5–7 минут

Подготовка: `adb install -r deliverables/picpac-demo.apk` (Android) или
`xcrun simctl install … deliverables/Runner-simulator.app` (iOS-симулятор). Приложение поднимает mock внутри себя.

## Вопросы комиссии и ожидаемые ответы

**Почему не WebView с онлайн-редактором?** Нативный редактор работает офлайн, документ локальный,
а превью, preflight и PDF используют один layout-код, поэтому экран и печать не расходятся.

**Где хранятся фото и документ?** Оригиналы — на устройстве, документ — JSON-снапшот (атомарная запись,
дебаунс 500 мс, N ревизий) плюс индекс в Drift. На сервер уходят только явно загруженные файлы.

**Что если сеть пропала?** Черновик сохраняется локально, заказ уходит в очередь с тем же
`Idempotency-Key`; повтор не создаёт второй заказ.

**Откуда берутся цены и сроки?** Только из `POST /price` и ответа заказа. Клиент не умножает и не суммирует
деньги; в мультистрочной корзине берутся серверные котировки.

**Как проверяются роли?** На сервере: гость получает 403 на checkout и историю, клиент — на чужие заказы и
`/audit`, поддержка видит всё. Скрытие кнопок — только удобство.

**Что с PII и фото детей?** Токены в Keychain/Keystore, в логах нет тел запросов и телефонов, в модель уходит
превью и статистика, не оригиналы; EXIF/GPS вычищаются при импорте.

**Как обеспечивается идемпотентность оплаты?** Заказ до оплаты, один активный intent, истина — webhook и
`GET /payments/{id}`, переходы только вперёд, дубликаты вебхуков игнорируются.

**Что с качеством печати?** PDF рендерится по одному листу в 300 dpi из оригиналов; preflight предупреждает
о низком разрешении до оплаты.

**Масштабирование.** Stateless BFF перед Pixlpark/ERP, mock повторяет контракт; очередь заказов и вебхуков
идемпотентна; при росте — вынос рендера в очередь и CDN для превью.

## Отчёт о тестировании (обязательные критерии трека 2)

| Критерий | Результат | Как проверено |
|---|---|---|
| Запуск по инструкции ≤15 минут | PASS | `flutter pub get` + `./scripts/run.sh`, либо готовый APK |
| Вход минимум под двумя ролями | PASS | customer / support_agent, права на сервере |
| Каталог и цены через API | PASS | в UI нет цифр; данные из `GET /catalog`, `POST /price` |
| Проект с 10 фото, порядок, повторное открытие | PASS | снапшот + список проектов, восстановление после рестарта |
| HEIC с iPhone | PASS | нативная конвертация, EXIF/GPS вычищены (iOS и Android) |
| Preflight и предупреждения | PASS | пустой слот, низкое DPI, формат, safe-zone; override логируется |
| Пересчёт цены (опции/количество/доставка/промо) | PASS | только сервер |
| Повтор checkout без дубля | PASS | тот же ключ → тот же заказ, другой body → 422 |
| Офлайн: черновик и очередь | PASS | черновик на диске, повтор с тем же ключом |
| Статусная лента | PASS | принят → модерация → производство → готов → завершён |
| История заказа и тикет | PASS | состав, сумма, статус, связанное обращение |
| Удаление фото и аккаунта | PASS | каскад, два подтверждения |
| Аудит действий | PASS | актор, время, действие, объект, результат; PII маскируется |
| Секреты в репозитории | PASS | ключи только в env сервера, `.env` не коммитится |
